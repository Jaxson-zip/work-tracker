# 飞书配置

飞书有两个互相独立的用途，用哪个配哪个：

- **群通知**：群里的自定义机器人，接收转交、验收和每日摘要。
- **私聊记事**：企业自建应用的机器人，用户私聊它就能记录事务和待办。

## 群通知

1. 在目标群添加自定义机器人，开启签名校验。
2. 把地址和签名密钥写进 `WORKSPACE_WEBHOOKS`（团队 ID 的查询方法见 README）：

```json
{
  "11111111-1111-4111-8111-111111111111": {
    "url": "https://open.feishu.cn/open-apis/bot/v2/hook/REPLACE_WITH_HOOK_ID",
    "secret": "REPLACE_WITH_BOT_SIGNING_SECRET"
  }
}
```

只接受 `open.feishu.cn` 和 `open.larksuite.com` 的机器人地址。某个团队没配置时，消息不会发到别的群，通知页会提示“还没有配置群机器人”。

## 私聊记事

1. 在飞书开放平台创建企业自建应用，启用机器人能力，授予读取机器人私聊消息的权限。
2. 在事件与回调里启用加密，把 Encrypt Key 和 Verification Token 配成 `FEISHU_ENCRYPT_KEY`、`FEISHU_VERIFICATION_TOKEN`。
3. 请求地址填 `https://你的域名/api/feishu/events`，事件订阅“接收消息”。
4. 把 `VITE_FEISHU_BOT` 设为 `1` 并重新部署，通知页才会显示“绑定飞书”。
5. 用户在通知页生成绑定码，私聊机器人发送完整的绑定命令。

支持的命令（前缀和内容之间要有空格）：

```text
绑定 WT-网页生成的一次性绑定码
记录 今天与客户确认了交付范围
待办 明天9点 提交报告
任务 周五下午3点 跟进合同
```

只处理发给机器人的一对一文本消息，群消息和其他事件会被忽略。解析日期时用的时区依次取 `FEISHU_TIME_ZONE`、`APP_TIMEZONE`，都没有配置时用 `Asia/Shanghai`。

## 安全和重试

事件回调会校验签名、时间戳和解密后的 token，重复投递的事件不会重复记录。通知失败会按退避时间重试，最多 5 次。

## 验证范围

验签、命令解析和通知发送都有自动测试，使用加密样例和模拟的网络边界。**还没有在真实的飞书应用上验证过。**
